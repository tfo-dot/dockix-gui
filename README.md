# Dockix GUI

A graphical interface for [Dockix](https://github.com/tfo-dot/dockix) that just works (exists, and is blazingly fast).

# Why

Due to the way the project is divided, the frontend has no hope, and neither does backend, therefore this project exists just to provide some kind of graphical interface for the backend side of the project.

It's not a part of the actual project as not to give frontend the code to just copy and call it their own. Since they don't plan to work with the project I don't plan either.
